## 审核答辩要点（按权限逐条）

| 审核关注 | 答辩文案 |
|---|---|
| `debugger` 权限 | 仅用于两项用户主动开启的功能：①"CDP 精确截图"（Page.captureScreenshot，让目标标签页不在前台时也能截图）；②"AI 自动录制"（Input.dispatch* 执行用户描述的教程目标）。开启时 Chrome 原生显示"正在调试此浏览器"提示条，录制停止/失败立即 detach。绝不用于绕过安全策略或读取用户凭据。 |
| `<all_urls>` 主机权限 | ①录制时向用户正在操作的页面按需注入反馈脚本（截图成功提示 + 交互控件摘要），已从静态 content_scripts 改为录制期间 executeScript 按需注入并随导航重注入；②用户配置的 AI 接口多为不支持 CORS 的网关，需要从扩展进程直接 fetch。无任何后台常驻采集。 |
| 数据使用披露 | 无遥测、无账号、自有后端；AI 截图发送默认关闭。用户明确授权后，页面截图与必要上下文会发送到用户选择的 AI 服务商。交互文本会打码，但截图可能包含可见敏感信息，设置页和隐私政策均明确提示。隐私政策：`https://vincent623.github.io/tutorial-recorder/privacy-policy-zh.html`。 |
| 单一用途 | 将浏览器操作录制为可分享的图文教程。 |
