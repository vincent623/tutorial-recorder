## Highlights

- AI recording now uses synchronized Browser Observation data and opaque element references instead of screenshot-only coordinate guessing for routine DOM actions.
- Search-style input and submission are executed as one verified action, removing the long delay between typing and Enter.
- Tab and document identity are pinned through authorization and dispatch, with single-use action tickets and execution-time verification.
- CDP and `chrome.scripting` observation adapters share the same capability contract for regular DOM, Shadow DOM, and same-origin iframe content.
- High-risk, destructive, unknown-destination, and visual-fallback actions remain approval-bound; routine low-risk actions proceed without repeated confirmation.
- Debugger conflicts, extension-page startup, multi-window target selection, retries, takeover, and clean shutdown have dedicated regression coverage.

## Installation

Download `tutorial-recorder-v2.9.0.zip`, verify its SHA256 against `tutorial-recorder-v2.9.0.zip.sha256`, extract it, and load the extracted directory through the browser's extension developer mode.

AI recording sends screenshots and structured page observations to the model provider only after the user explicitly enables AI screenshot sharing and configures their own provider credentials.
